# 招募说明书素材库修改操作指引

## 场景 1：想改固定模板表述
优先入口：
- `[02_招募说明书模板.md](/systems/etf/02_招募说明书模板.md)`

配套检查：
- 是否涉及新增占位符
- 是否涉及条件块
- 是否会被参考口径在后续函数中覆盖

辅助索引：
- `02_表述来源映射表.md`
- `04_共享依赖清单.md`

## 场景 2：想改参考文档口径
优先入口：
- `01_参考素材索引.json`
- `[manual_regression_20260310_201555](/systems/etf/manual_regression_20260310_201555)`

推荐步骤：
1. 先在 `01_参考素材索引.json` 确认变体键
2. 找到对应 `docx/txt`
3. 判断问题出在参考底稿，还是出在提取/替换函数
4. 如有必要，再去 `03_函数映射表.json` 查对应函数

## 场景 3：想改函数内硬编码表述
优先入口：
- `03_函数映射表.json`
- `[app.py](/systems/etf/app.py)`

推荐步骤：
1. 先按表述主题确定是哪个函数负责
2. 判断该文案是否应保留在函数里
3. 本次若只是小修，直接改函数
4. 若后续频繁变更，再考虑第二阶段抽离到独立素材文件

## 场景 4：想排查“为什么改了模板没生效”
优先检查：
1. 是否被参考口径覆盖
2. 是否被 `_replace_manual_reference_text` 或 `_replace_reference_fund_name` 改写
3. 是否在 `_apply_reference_fixed_content` 或 `_apply_canonical_reference_overrides` 被二次覆盖
4. 是否是 Word 导出层复用了参考 `docx`

## 场景 5：网页里怎么维护
模板编辑器现在支持：
- 根目录 `.md/.json` 文件
- `prospectus_materials/` 子目录下的 `.md/.json` 文件

建议做法：
- 先在网页里改说明、映射、索引类文件
- 真正改生成口径时，再按素材库给出的入口去改模板、条款库或函数
