# 招募说明书共享依赖清单

以下内容虽然不全属于“招募说明书专属素材”，但会直接影响招募说明书最终输出，后续维护时需要一起登记。

## 1. 共享模板与规则文件
- `[02_招募说明书模板.md](/systems/etf/02_招募说明书模板.md)`
  招募说明书正文模板骨架
- `[08_招募说明书差异条款库.json](/systems/etf/08_招募说明书差异条款库.json)`
  招募说明书差异条款和条件逻辑
- `[03_变量定义表.json](/systems/etf/03_变量定义表.json)`
  变量定义会影响模板替换与部分招募逻辑
- `[06_要素录入表.md](/systems/etf/06_要素录入表.md)`
  录入说明影响字段来源和维护理解

## 2. 共享函数入口
- `_derive_variables`
  合同与招募说明书共用的变量推导入口
- `_inject_clause_texts`
  共享条款注入入口，部分招募说明书口径也依赖这里
- `_reference_prospectus_docx_candidates` / `_resolve_reference_prospectus_docx`
  参考招募说明书版式定位逻辑

## 3. 参考资产目录
- `[manual_regression_20260310_201555](/systems/etf/manual_regression_20260310_201555)`
  当前招募说明书参考 `docx/txt` 资产统一存放目录

## 4. 维护提醒
- 如果招募说明书输出异常，不要只看模板。
- 先判断问题属于：
  模板层 / 差异规则层 / 参考资产层 / 共享函数层 / 导出层
- 本清单的意义，是提醒维护者不要漏掉共享入口。
